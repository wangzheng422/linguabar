# LinguaBar 0.1.0

<!-- AI-Author: Codex (OpenAI model not exposed by runtime) -->

Initial preview / 首个预览版。macOS 15+ · Apple Silicon (arm64).

Native live captions for Google Meet, Chrome, Teams and system audio. English and Korean transcription with Chinese translation; Chinese transcription-only mode. Adjustable split panes, font size, background opacity, persistent preferences, bounded history and scroll following.

原生会议实时字幕：英文／韩文转写并翻译中文，中文仅转写。支持可拖动分隔条、字号与透明度、偏好记忆、历史上限和自动滚动跟随。

## Known limitations / 已知限制

- arm64 only; Intel not validated.
- Chinese UI labels; bilingual project documentation.
- Chrome capture can include other tabs, not just Meet.
- Apple Speech is not forced offline; language downloads may be required.
- Pause-based punctuation is approximate.
- Source/language switching requires stopping captions.
- Permission prompts and recognition quality need validation on other Macs.

Include the matching source archive and AGPL license with the binary release.
